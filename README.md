📚 Book Store Management System
A RESTful API backend for managing a book store, built with Go, GORM, and SQL Server. This system provides complete CRUD operations for book management with a clean architecture.
✨ Features

📖 Complete CRUD Operations - Create, Read, Update, and Delete books
🗄️ SQL Server Database - Running in Docker container
🔄 GORM ORM - Elegant database operations with migrations
🌐 RESTful API - Clean and intuitive API endpoints
🔀 CORS Enabled - Ready for frontend integration
🗑️ Soft Deletes - Books are marked as deleted, not permanently removed
⚡ Fast & Lightweight - Efficient Go backend
